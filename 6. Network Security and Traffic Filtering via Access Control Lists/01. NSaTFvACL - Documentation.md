## PROJECT
 * Network Security and Traffic Filtering via Access Control Lists
   - 

## OVERVIEW
 * Problem 
    - MANNEL GROUP has expanded and have added  GUEST PC segment to their network so visiting clients can access the internet.

    - Guest must be able to reach the internet, but they must be completely blocked from touching any internal HR or IT devices.

    - Only the HR department should be allowed to access secure HR resources. IT users must be blocked from accessing the HR subnet, but HR users should still be able to initiate connections to IT.

    - The IT department needs to ping the router for troubleshooting, but guests should be blocked form pinging the router's  internal interfaces. 

 * Solution
    - This project showcases basic security filtering at layer 3 security boundaries using Cisco Access Control Lists (ACLs) mapped to a multi-subnets Router-on-a-Stick (RoaS) topology. ese rules will evaluates packets based on their source IP, destination IP, and protocol type, allowing you to selectively permit or deny traffic before it crosses network boundaries.

## CONFIGURATIONS
    - Set up IP addresses, subnet mask and default gateway for endpoint PCs.
    - Provision the VLAN database and assign our physical interfaces to their correct user access zones and trunk pathways.
    - created a standard ACL
    - Isolated the guest subnet using the extended ACL

## TECHNOLOGIES USED
    - Standard IP Access Control List
    - Extended IP Access Control List
    - Wildcard masking Subnet Identification
    - Router subinterface mapping
    - inter-vlan routing
