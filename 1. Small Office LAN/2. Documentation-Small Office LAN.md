## PROJECT 
Small Office LAN 

## OVERVIEW

 * Problem:
  - An expanding consulting office requires a scalable network infrastructure to support multiple incoming team members and centralised hardware peripherals. The infrastructure must eliminate individual point-to-point physical dependencies while maximising data tranfer speed and preventing transmission collision.


 * Solution: 
  - This project demonstrate the deployment and configuration of a local star-topology enterprise using a centralised Cisco catalyst 2960 layer 2 switch. It scales a local workspace an Isolated peer-to-peer link to multi-node office environment containing four endpoints and a shared network utility assets.

## TECHNOLOGIES USED
 - Cisco Catalyst 2960   Switch
 - Physical and logical star topology
 - Ethernet copper straight-through media
 - Cisco CLI, ICMP Echo verification

## Verification
Local connectivity was verified using sequencial mesh pings across all workstations to the static printer target address. Additionally, runtimem layer 2 frame analysis was executed on the switch using  <show mac address-table>  command, confirming proper hardware address learning across active interface port Fa0/1 to Fa0/5.
