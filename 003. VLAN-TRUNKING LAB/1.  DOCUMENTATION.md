## OBJECTIVE
  - The objective of this lab is to understand how to configure VLANs and trunking  on Cisco multiple  Switches and also familiarize with the commands on Cisco IOS to validate and check configurations.  

## PURPOSE
  - VLANs allow for segmentation of network and multiple or broadcast domains and trunking allows for seamless switch to switch communication. 


## TECHNOLOGY USED
  - Switches
  - PCs 
  - VLANS
  - Ethernet cables

## CONFIGURATION 
  - configured HOSTNAME
  - configured VLAN
  - verified vlan on both switches using <show vlan brief> command on privilege EXEC. mode.
  - configured access port and assigned vlans
  - verified access port and vlan assignment 
  - configured trunk port 
  - verified interface trunk port with the command <show interface trunk>

## DESIRED OUTCOME
  - pinged PC7 (on VLAN 10) from PC1  (on VLAN 10) and the outcome was successfull.
  - pinged PC7 (on VLAN 10) from PC2 (on VLAN 20) and the outcome was unsuccessful.
