## PROJECT 
Enterprise Micro-Segmentation via Virtual LANs

## OVERVIEW

 * Problem: 
   - A Small organisation has moved into a larger, permanent building. Their Engineering staff and Human Resources team are the same physical network space. 

 * Solution: 
   - This project introduces Virtual Local Area networks (VLANs) and 802.1Q Network trunking. Which will break down a single physical switch into multiple, isolated virtual switches. This will create a distinct administrative boundaries for different corporate department and access ports for individual users and implements a high -capacity trunk link to pass traffic across infrastructure nodes safely.

## TECHNOLOGY USED 
   - Virtual Local network 
   - Broadcast domain Separation
   - IEEE 802.1q tagged encaptulation Protocol
   - Access mode port binding
   - inter-switch multiplexing trunk path

## CONFIGURATIONS
   - configured static IP addresses to endpoint devices.
   - Database provisioning and port mapping on the two switches.
   - Configured the inter-Switch trunk port.
## DESIRED OUTCOMES
 * A secure, segmented enterprise switching fabric where departmental traffic is strictly isolated locally and safely bundled across distribution links.
