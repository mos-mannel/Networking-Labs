## PROJECT
  Inter-VLAN Routing via Router-on-a-stick 

## OVERVIEW
 * Problem: 
   - After a small company has moved to a larger building which demanded for the implementation of virtual Area Network (VLAN) which has birth  another constraints. The devices in HR department  (VLAN 10) needs to communicate with Engineering department (VLAN 20).

 * Solution: 
   - This project introduces Inter-VLAN routing using a router configured with logical subinterfaces. The single physical router interfaces will be splitted into virtual subinterfaces, one for each VLAN where each subinterface will act as the "Default Gateway" for its respective department.


## TECHNOLOGY USED
  - Inter-VLAN logical routing
  - subinterface division 
  - IEEE 802.1Q trunk headers(dot1q)
  - Routing tables
  - Gateway assignment prpofiles
  - Routing Analysis


## CONFIGURATIONS 
  - Router interface configured to UP
  - configured router subinterfaces for both VLANs
  - configured the default gateway for all end devices
  - configured a trunk link on the switch to router interface.
## DESIRED OUTCOME
 - Secure, scalable inter-VLAN communication where different subnets can seamlessly route data to each other over a single shared physical uplink.
